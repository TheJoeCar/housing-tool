Pick the houses without picking fights

Everyone ranks the group — strict order, or the tie levels the organiser picked. Rankings travel as encrypted chips in the group chat. One trusted key holder turns the chips into the fairest split for any layout you name — quiet arithmetic, no numbered scores, no blaming.

Nothing leaves your device unencrypted. Rankings never touch a server — the page does everything locally, chips open only with the one private key, and the results code carries only how strongly pairs of friends pull towards each other, never individual rankings.
